Zum Generieren eines Clients kann das npm Paket ng-openapi-gen genutzt werden. Das geht am einfachsten in der WSL. Falls ihr noch keine WSL habt, siehe hierzu die entsprechende Seite im Wiki. Das Programm muss zunächst installiert werden. Dazu in der WSL einmal folgenden Befehl ausführen:

Dann das Skript ausführen. Dazu mit der WSL aus dem Projektverzeichnis bash generate-api.bash ausführen. Das geht auch aus IntelliJ heraus. Dort das Terminal öffnen und einmal bash eingeben, damit ihr in der WSL landet. Dann seid ihr auch sofort im richtigen Projektverzeichnis. Bei der Ausführung des Skripts mit bash generate-api.bash werden die sourcen generiert und können ab dann in eurer Anwendung genutzt werden. Das Skript könnt ihr jedes mal neu ausführen, wenn sich etwas an eurer api-spec geändert hat.
