Olb Base

Die Komponente olb-base stellt die Basis einer OLB-Frontend-Anwendung dar. Sie stellt die Headerleiste sowie die seitliche Navigationsleiste bereit. Außerdem können der angemeldete Benutzer und die aktuelle Kordoba-Umgebung (nur int) angezeigt werden. Diese Demo-Anwendung verwendet genau diese Komponente, um die Rahmenstruktur bereitzustellen. Parameter wie ein Titel, Logo und eine Anwendungsversion können hier angegeben werden.

Menüaufbau

Das Navigationsmenü wird als json Objekt deklariert und dem Parameter menuItems zugewiesen. Es kann in der Sidebar in einen Minimodus geschaltet werden, oder als Menü im Banner/Header dargestellt werden. Beides kann einfach mittels der dargestellten Button umgeschaltet werden.

Es gibt die Möglichkeit einfache Links, Links mit Unterlinks(children), funktionslose Ordner oder einfache Titel darzustellen. Außerdem kann zu einem Link ein sogenannter anchor angegeben werden. Dieser gibt die Stelle in der Ziel Komponente an, an die automatisch gesprungen wird sobald auf den Link geklickt wird. Vorraussetzung dafür ist ein entsprechender Eintrag im routing. Banner-Icons

Über den OlbBannerIconService können links neben dem User-Icon beliebig viele Material-Icons ergänzt werden. Jedes Icon erhält einen externen Link, der beim Klick in einem neuen Tab geöffnet wird. Nach dem Hinzufügen lassen sich Badge und Farbe jederzeit ändern, einzelne Icons können wieder entfernt werden.
