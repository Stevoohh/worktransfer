Angular Updates

Schritt 1: Einen neuen Feature Branch für das Update machen. Der Branch muss clean ohne Änderungen sein.

Schritt 2: Auf der cmd:

    ng update {{ "@" }}angular/cli {{ "@" }}angular/core 

    Zusätzlich muss Eslint aktualisiert/installiert werden. Falls nicht breits geschehen, hierzu Schritt 3.2 Eslint und Prettier aus der Installation ausführen, ansonsten ng update.

Schritt 3: Commit (ohne Push)

Schritt 4: Auf der cmd:

    ng update {{ "@" }}angular/material
  
    Optional kann man mit: 'ng update' geschaut werden, welche Packete veraltet sind um diese dann zu aktualisieren

Schritt 5: Falls ihr bereits MaterialDesign v3 verwendet (Angularbase ab 19.2.0), dann folgende Einträge aus der src/styles.scss entfernen (falls vorhanden) 

   {{ "@" }}import "{{ "@" }}olb/angular-base/assets/styles/material-overwrites"; 
   {{ "@" }}import "{{ "@" }}olb/angular-base/assets/styles/olb-classes";

Schritt 6: npm start und prüfen, ob die Anwendung noch läuft

Schritt 7: Commit and push. Wenn ihr wollt, könnt ihr eure Commits noch squashen, aber wenn ihr nicht wisst, was das bedeutet, dann lasst es lieber (ich lasse es selbst auch in der Regel sein)

Schritt 8: Fertig!
