Olb Form Fields

Die Bibliothek bietet verschiedene Formularfelder. Folgend eine Übersicht.

Datum

Ein Wrapper für den Angular Material Datepicker

Name Typ Datentyp Beschreibung
control Input FormControl Pflichtfeld
minDate Input moment.Moment Mindestdatum
maxDate Input moment.Moment Maximales Datum
label Input string Name / Überschrift des Formularfelds, Default: "Datum"
appearance Input string Grafische Darstellung des Formularfelds 'outline', 'fill', Default: "outline"
validationErrors Input [key: string]: string | null Optionale Validierungstexte
hintLabel Input string Hinweis unterhalb des Formularfeldes
dateFilterFn Input DateFilterFn<moment.Moment | null> Funktion, die für den Datepicker filtert, welche Daten erlaubt sind
blur Output FocusEvent | MatDatepickerInputEvent<moment.Moment> Event, das getriggert wird, wenn ein Datum gesetzt wird

Benutzer

Ein Wrapper für das Angular Material Autocomplete

Name Typ Datentyp Beschreibung
userFormControl Input FormControl Pflichtfeld
validationErrors Input [key: string]: string | null Optionale Validierungstexte
optionSelected Output optionSelected<User> Event, das getriggert wird, wenn ein Benutzer ausgewählt wurde

Kontonummer

Dieses Eingabefeld ist für eine Kontonummer gedacht mit belieber Anzahl an positiver Zahlen (default ist 10stellig).
Es müssen und können auch nur soviel Zahlen eingegeben werden wie im length-Parameter angegeben

Name Typ Datentyp Beschreibung
control Input FormControl Pflichtfeld
label Input string Name / Überschrift des Formularfelds, Default: "Kontonummer"
appearance Input MatFormFieldAppearance Aussehen des Formularfelds (umranded=outline oder ohne Rand=fill), Default: "fill"
icon Input string Name des Icons welches am Ende des Eingabefelds angezeigt wird
length Input number Anzahl der min und max (also exakt) anzugebenen positiven Zahlen
showHint Input boolean Gibt an ob der Hinweistext zu den erwarteten Zahlen unter dem Eingabefeld angezeigt werden soll
