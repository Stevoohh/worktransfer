Simplemattable

Tabellen können mit der Library simplemattable erstellt werden. Dazu zunächst das Paket in die package.json aufnehmen:

  "simplemattable": "^17.0.0",

Dann das Modul im AppModule importieren:

  imports: [
    ...
    SimplemattableModule,
  ]
